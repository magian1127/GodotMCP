# 导出你的游戏（构建中的扩展脚本）

用户导出游戏时，Toolkit 的导出插件会在所有模式下剥离插件、扩展的**非脚本**文件以及 `res://.mcp.json`；当脚本导出模式为 **Text** 时，也会剥离扩展**脚本**。

## 二进制 token 注意事项（Godot 4.3+）

在 **binary-token** 脚本模式（Godot 4.3+ 默认模式）下，引擎会在剥离操作运行前将每个 `.gd` 编译为 `.gdc`，因此你的扩展 `.gd` 会以无作用的孤立 `.gdc` 形式随包发布——运行时不会加载，对游戏没有影响。插件会在导出时发出警告，并列出泄漏的扩展。

这是长期存在的引擎限制（godotengine/godot#4054），并非扩展特有。Godot 4.2 没有二进制 token 模式，因此扩展脚本始终能干净剥离。

## 干净剥离

以下任一方式都可以移除孤立的 `.gdc`：

- 在导出预设中将 **Script Export Mode** 设为 **Text**，或
- 将扩展的 `.gd` 路径加入预设的 **Resources → exclude filter**。

## C#

C# 扩展会编译进项目的 .NET 程序集，无法按类剥离。使用 `if (!Engine.IsEditorHint()) return;` 保护仅编辑器工作，确保构建中不会运行任何内容。
