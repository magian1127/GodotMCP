# 安全边界

桥接控制一个本地编辑器，并拥有与该编辑器相同的文件系统权限。

- 将网络监听保持在 `127.0.0.1`，并保留按会话进行的令牌认证。
- 将文件操作限制在 `res://` 或明确列入白名单的 `user://` 路径内。将绝对路径、路径遍历、UNC 路径和插件自修改视为拒绝执行的请求。
- 先进行只读检查，再进行变更。不要禁用服务端路径守卫、审计日志、响应上限或不可信内容封装。
- 将 `execute_code`、任意节点方法调用、递归删除、外部 URL 访问以及项目/插件配置视为高风险操作。`execute_code` 与 `node_call_method` 只在服务端以 `GODOT_MCP_UNSAFE=1` 启动后出现在 unsafe 组；只为用户明确授权的当前操作启用。存在类型化替代工具时应使用替代工具，并明确限定受影响范围。
- 使用时间控制时保留运行中项目自身的暂停状态，并在清理阶段解除冻结。
- 不要在导出的游戏中暴露运行时 autoload。插件仅在导出期间启用时才会自行移除；生产构建前请核验导出设置。
